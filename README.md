# News Management System

This project is a web-based news management system developed using PHP, MySQL, HTML, CSS, and JavaScript. It provides a basic administrative interface for managing news content, categories, publication status, and uploaded media.

The system demonstrates the development of a dynamic web application that connects user interaction with database operations. It includes common content management features such as creating, editing, deleting, searching, and displaying news records.

## Main Features

- Admin login and session management
- Add, update, and delete news articles
- Manage news categories
- Publish or save articles as drafts
- Upload and display images
- Search and filter news content
- Display dashboard statistics

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Project Purpose

This project was developed to apply core web development concepts, including server-side programming, database connectivity, CRUD operations, form handling, file uploads, and basic administrative system design.

## How to Run

1. Install XAMPP.
2. Place the project folder inside `htdocs`.
3. Start Apache and MySQL.
4. Import `rose_db.sql` into phpMyAdmin.
5. Open the project using `localhost` in the browser.
